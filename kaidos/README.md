# KaDOS — прототип DOSBox-подобного ядра для KaiOS (Nokia 800 Tough)

**Что это.** Экспериментальная заготовка: попытка собрать минимальное DOS-окружение
(x86-интерпретатор + VGA-эмуляция + sound blaster) в .krn-пакет для KaiOS 2.5.x.

**Статус: НЕ РАБОТАЕТ для Fallout 2.** Это честный каркас, а не эмулятор.
Почему — см. раздел «Реальность» ниже.

## Реальность (прочитай первым)

1. **KaiOS приложения = Gecko-приложения.** .krn — это zip с manifest.webapp +
   HTML/JS/CSS (+ нативные библиотеки только через Firefox OS add-on API, который
   Nokia на 2.5.2 почти полностью порезан). Т.е. «нативный» код здесь — это
   JavaScript в Gecko, а не C++ в процессе.
2. **Fallout 2 требует x86-emulation полного цикла**: 32-bit protected mode,
   DOS-сервисы, direct draw-like доступ к VGA, MIDI/GUS, ~4 МБ RAM процесса.
   В JS-песочнице Gecko с лимитом памяти приложения ~40–60 МБ и без JIT-компиляции
   (на 800 Tough JIT выключен политикой безопасности) производительность
   динамической рекомпиляции недостижима. Интерпретатор на JS даст ~0.5–2 MIPS —
   Fallout 2 требует ~15–40 MIPS.
3. Именно поэтому существующие «порты» (ACME/DOSBox на Smartwatch/Kaios-устройствах)
   либо работают на cut-down играх эпохи CGA (Prince of Persia, Doom 1993 в low-res),
   либо это стриминг. Полноценная FO2 не шла ни у кого; RP тем более.
4. FreeDINK (переписанный DINK-движок, C++) теоретически компилируется в asm.js/WASM,
   но ему нужны данные оригинального DINK-движка (артефакты из исходников GOG-версии
   Dink Smallwood), а Fallout 2 использует закрытый исходник DINK v1.02d — WASM-порт
   потребовал бы переноса всего рендера/скриптования, что и есть «написать движок заново».

## Что здесь есть

- `src/vm.c` — скелет интерпретатора x86 (только real mode, ~30 инструкций)
- `src/vga.c` — кольцевой буфер framebuffer 320x200 -> масштабирование в canvas
- `src/dos.c` — stub прерываний INT 21h (функции 09h, 4Ch, 3Fh/40h через виртуальный FAT)
- `webapp/manifest.webapp` — манифест KaiOS-приложения
- `build.sh` — сборка Emscripten -> wasm + упаковка .krn

Это ~неделя работы студента, а не продукт. Собрать можно, запустить COM-файл
типа DEBUG.EXE — может быть; запустить master.dat Fallout 2 — нет.

## Сборка (для интересующихся)

```bash
emcc src/*.c -O2 -s WASM=1 -s USE_SDL=0 \
    -s EXPORTED_FUNCTIONS='["_vm_step","_vga_poll"]' \
    -o webapp/js/kados.js
cd webapp && zip -r ../kados.krn . && cd ..
# установка: Wallace Toolbox -> Install .krn (или pm install)
```

## Что реально делать с Fallout 2 на этом телефоне

1. **Стриминг**: Sunshine на ПК + KaiRay-клиент (GitHub: kai-ray) по Wi-Fi. Играется.
2. **Fallout Tactics/1 на Android-ТВ приставке** за копейки + HDMI на телевизор.
3. Дождаться когда кто-то соберёт fallout2-ce (open-source порт движка!) под KaiOS WASM.
   Движок уже переписан на SDL2/C++, компилируется в emscripten — вот ЭТО реалистичный путь.
   Порт движка ≠ порт данных игры: master.dat всё равно нужен купленный.
